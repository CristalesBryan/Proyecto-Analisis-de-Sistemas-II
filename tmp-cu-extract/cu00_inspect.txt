008 [Normal] left=None 1. Introducción.
009 [Normal] left=None 1.1. Objetivo.
010 [Normal] left=None El presente CU tiene como objetivo describir la interacción del ciudadano y del usuario municipal con el Portal Público del Sistema QRDS. El portal permite acceder sin autenticación al registro de quejas, reclamos, denuncias y sugerencias y a la consulta de seguimiento; además, integra el proceso de inicio de sesión para los usuarios internos autorizados.
012 [Normal] left=None 2. Definición Caso de Uso
013 [Normal] left=None 2.1 Actores.
014 [Normal] left=None 2.1.1. Ciudadano / Usuario Público.
015 [Normal] left=None 2.1.2. Usuario Municipal.
016 [Normal] left=None 2.1.3. Sistema QRDS.
017 [Normal] left=None 2.1.4. Servidor Web.
019 [Normal] left=None 2.2 Precondiciones.
020 [Normal] left=None 2.2.1. Que el servidor web y los servicios requeridos por el Sistema QRDS se encuentren activos.
021 [Normal] left=None 2.2.2. Que la base de datos se encuentre operativa.
022 [Normal] left=None 2.2.3. Que el Portal Público se encuentre disponible mediante HTTPS.
023 [Normal] left=None 2.2.4. Para iniciar sesión, el usuario municipal debe contar con un usuario activo dentro de la aplicación. RN01.1
025 [Normal] left=None 2.3 Flujo Normal Básico
026 [Normal] left=None 1. El usuario ingresa a la URL del Portal Público del Sistema QRDS.
027 [Normal] left=None 2. El sistema carga la página principal sin requerir autenticación.
028 [Normal] left=None 3. El sistema muestra las opciones principales:
029 [Normal] left=None    a. Registrar Queja, Reclamo, Denuncia o Sugerencia, Consultar Seguimiento de Caso e Iniciar Sesión.
030 [List Paragraph] left=457200 1. El ciudadano selecciona la opción “Registrar Queja”.
031 [List Paragraph] left=457200 2. El sistema redirige al formulario público correspondiente al CU-03 sin requerir autenticación.
032 [List Paragraph] left=457200 3. El registro continúa en CU-03 y debe cumplir las reglas de registro definidas para ese caso de uso. RN03
033 [Normal] left=None 4. Fin del caso de uso.
035 [Normal] left=None 2.4 Flujos Alternos.
037 [Normal] left=None FA01: Iniciar Sesión
038 [Normal] left=None 1. El usuario selecciona la opción “Iniciar Sesión”.
039 [Normal] left=None 2. El sistema despliega los siguientes campos:
040 [Normal] left=None    a. Usuario.
041 [Normal] left=None    b. Contraseña.
042 [Normal] left=None 3. El usuario ingresa los datos correspondientes.
043 [Normal] left=None 4. El usuario selecciona el botón “Acceder”.
044 [Normal] left=None 6. El sistema valida que el usuario se encuentre activo, que las credenciales sean válidas RN01.1 RN01.2
045 [Normal] left=None 7. Si las credenciales son válidas, el sistema registra el inicio de sesión en la bitácora. RN01.3
046 [Normal] left=None 8. El sistema permite el ingreso a la bandeja principal.
047 [Normal] left=None 9. Fin del flujo alterno.

135 [Normal] left=None 2.5 Postcondiciones.
136 [Normal] left=None 2.5.1. El ciudadano accedió al módulo público seleccionado o el usuario municipal inició sesión correctamente.
137 [Normal] left=None 2.5.2. Si se inició o cerró sesión, el evento quedó registrado en la bitácora de auditoría con los datos requeridos.
138 [Normal] left=None 2.5.3. La consulta pública no expone información restringida ni modifica el caso.
139 [Normal] left=None 2.5.4. Si la autenticación falló, no se creó una sesión válida ni se concedió acceso a funciones internas.
